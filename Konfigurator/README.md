# Einkaufsliste Konfigurator

Zeigt alle Einkaufslisten des verbundenen Bring!-Kontos und legt sie per Klick als **Einkaufsliste**-Instanz an. Bereits angelegte Listen werden erkannt; Instanzen, deren Liste im Konto nicht mehr existiert, werden ebenfalls angezeigt und können gelöscht werden.

Beim Anlegen des Konfigurators wird automatisch eine **Einkaufsliste Konto**-Instanz erstellt, falls noch keine vorhanden ist.
